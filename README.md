# Эмулятор оболочки ОС с VFS

## 1. Общее описание
GUI-эмулятор командной строки UNIX-подобной ОС (Python 3, tkinter).
Реализовано: REPL, парсер с раскрытием `$VAR`, заглушки `ls`/`cd`,
`exit`, параметры командной строки и стартовые скрипты (этапы 1-2).

## 2. Функции и настройки
Параметры запуска:
- `--vfs ПУТЬ` - путь к физическому расположению VFS;
- `--script ПУТЬ` - стартовый скрипт (ввод и вывод показываются на
  экране, выполнение останавливается на первой ошибке; строки с `#` и
  пустые строки пропускаются);
- `--headless` - консольный режим для автотестов.

При запуске все параметры выводятся отладочными строками `[debug]`.

## 3. Сборка и тесты
    ./run.sh [параметры]
    PYTHONPATH=src python3 -m unittest discover -s tests
    EMU_FLAGS=--headless ./tests/stage2.sh

## 4. Примеры
    ./run.sh --script tests/data/stage1_demo.txt
