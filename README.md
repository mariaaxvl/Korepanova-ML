# Эмулятор оболочки ОС с VFS

## 1. Общее описание
GUI-эмулятор командной строки UNIX-подобной ОС (Python 3, tkinter).
Реализован этап 1: REPL, парсер с раскрытием `$VAR`, заглушки `ls`/`cd`,
команда `exit`. Заголовок окна содержит имя `VFS`.

## 2. Функции и настройки
- `ls`, `cd` - заглушки, печатают своё имя и аргументы.
- `exit [код]` - завершает работу.
- Парсер: слова по пробелам, кавычки `'..'` и `".."`, `\` и `$VAR`,
  `${VAR}` (в одинарных кавычках переменные не раскрываются).

## 3. Сборка и тесты
    ./run.sh
    PYTHONPATH=src python3 -m unittest discover -s tests

## 4. Примеры
    vfs:/$ cd $HOME
    cd /home/user
    vfs:/$ foo
    foo: command not found
