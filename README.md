# Эмулятор оболочки ОС с VFS

## 1. Общее описание
GUI-эмулятор командной строки UNIX-подобной ОС (Python 3, tkinter).
Реализовано: REPL, парсер с раскрытием `$VAR`, параметры запуска,
стартовые скрипты и виртуальная ФС из ZIP-архива (этапы 1-3).

## 2. Функции и настройки
Параметры запуска:
- `--vfs ПУТЬ` - ZIP-архив с VFS (загружается целиком в память,
  на диск ничего не распаковывается);
- `--script ПУТЬ` - стартовый скрипт: ввод и вывод показываются на
  экране, остановка на первой ошибке, `#` и пустые строки пропускаются;
- `--headless` - консольный режим для автотестов.

Команды:
- `ls [путь]`, `cd [путь]` - навигация (без `--vfs` - заглушки);
- `pwd` - текущий каталог;
- `exit [код]` - выход.

## 3. Сборка и тесты
    ./run.sh [параметры]
    PYTHONPATH=src python3 -m unittest discover -s tests
    EMU_FLAGS=--headless ./tests/stage2.sh
    EMU_FLAGS=--headless ./tests/stage3.sh

Тестовые архивы создаются `tests/make_vfs.py` в `tests/vfs/`
(в репозиторий не добавляются).

## 4. Примеры
    python3 tests/make_vfs.py
    ./run.sh --vfs tests/vfs/deep.zip --script tests/data/vfs_deep.txt
